GitCode 授权

Star / Issue 任务需要 GitCode 访问令牌（PAT），且该 GitCode 账号必须先绑定到华为云。

如何获取访问令牌
  1. 点击打开 GitCode 访问令牌页面（需先登录 GitCode）
  2. 点「新建令牌」，名称随意，如 hwcloud-grow
  3. 权限勾选：项目读取项目写入 Issue 读写PR 读写 （即 repo / projects 相关权限）
  4. 创建后立即复制令牌（只显示一次），粘贴到下方输入框
⚠️ 该 GitCode 账号尚未绑定华为云
必须先绑定，Star / Issue 才会计分。前提：你当前浏览器已登录该华为云账号。
前往绑定 →
本页只保存令牌到服务器本地文件（权限 600），不会外传。
令牌仅用于调用 GitCode OpenAPI 完成 Star / 提 Issue。
